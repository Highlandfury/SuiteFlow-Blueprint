# Appointment Brief — Finance Controller (part-time governance role)

**SuiteFlow hotel platform programme · September 2026**

## The programme

SuiteFlow is a hotel management platform being built for a Nigerian pilot (200-room Lagos property profile). The target-state blueprint is complete and entering acceptance; delivery runs to a pilot-ready reference release on **10 March 2027**. The programme follows a documented governance charter with explicit approval authorities, and an independent acceptance review has already resolved all findings. The pilot is currently a **synthetic reference environment** (no real property or guest data), so the role is governance, not operations.

## The role

**Purpose:** own the programme's financial policy, architecture and controls sign-off — the finance authority named in the programme charter.

**What you approve (scoped list):**
- The financial architecture (posting model, revenue recognition, deposits, reconciliation, close).
- Accounting-boundary decisions ADR-005…008 (revenue/direct bill; business-day close; deposits/forfeiture; invoice authority).
- Authority-limit defaults and the consolidated refund/payout/waiver table.
- Month/day close governance (certification, reopen authority).
- Tax configuration together with the engaged tax adviser (tax positions stay marked unverified until advice lands).
- Golden-day financial acceptance at the reference release.

**What the role does not do:** run daily accounting; approve spend or contracts; make personnel decisions.

## Time commitment (provisional)

- Ongoing: **3–5 hours/month** (review requests, a monthly governance check-in, query responses).
- Acceptance sitting: one 90-minute session (or by 14 October for the first sitting).

## Independence and term
